## 💡 Proyectos Destacados

### 1️⃣ [Detección Inteligente de Fraude Financiero (ML)](./proyectos/01-deteccion-fraude-ml)
* **Descripción:** Modelo predictivo supervisado en Python para la identificación de transacciones anómalas en tiempo real.
* **Técnicas:** Balanceo de datos fuertemente imbalanceados con `SMOTE` y clasificación avanzada con `XGBoost`.
* **Impacto:** Reducción del **34%** en falsos positivos y detección oportuna de patrones fraudulentos.

### 2️⃣ [Dashboard de Control Operativo y SLAs (BI)](./proyectos/02-dashboard-bi-operativo)
* **Descripción:** Tablero interactivo en Power BI para control de KPIs, tiempos de respuesta y detección de demoras operativas.
* **Técnicas:** Modelado de datos en estrella, fórmulas `DAX` avanzadas y automatización de refrescos.
* **Impacto:** Automatización total de reportes semanales y optimización de tiempos de ciclo en **+25%**.
